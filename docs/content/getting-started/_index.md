Welcome to the documentation for **`github.com/raitucarp/epub`**!

Whether you need to extract chapters and metadata from eBooks, compile articles and documentation into readable EPUBs for e-readers, or dynamically update metadata on existing files, this library provides an intuitive and robust set of tools.

- [**Quickstart**]({{< relref "quickstart.md" >}}): A 5-minute hands-on guide covering the three main operations: reading, creating, and editing.
